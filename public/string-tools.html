Base64 について

  • 日本語などは UTF-8 として変換します。ほかのサイトやプログラムと同じ結果になります。
  • JWT や URL に入れる場合は「URL セーフ」を使います。
  • 画像をファイルで選ぶと、HTML や CSS に直接書ける data URL を作れます。

ハッシュと UUID について

  • MD5・SHA-1 は古い方式です。パスワードの保存などには使わないでください。
  • UUID はブラウザの安全な乱数で作ります。
