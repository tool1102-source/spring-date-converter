データの変換を、その場で。

JSON・CSV・Excel・日付・PDF・文字列。開発やデータ作業でよく使う変換を、ブラウザだけで済ませられるツール集です。

  • 無料・登録不要
  • データはサーバーに送られない
  • 入力するとすぐ結果が出る

ツール一覧

  • 日付・Epoch Time 変換

    UNIX時間と日本時間・UTC の相互変換。日付の書き方もまとめて変換できます。

    秒・ミリ秒を自動判別複数行

  • JSON ⇄ CSV 変換

    JSON と CSV・TSV の相互変換。入れ子の JSON は列に展開します。

    TSVExcel 用 BOM

  • Excel ⇄ CSV 変換

    Excel のシートを CSV に、CSV を Excel ファイルに。中身を確認してから保存できます。

    xlsx・xlsShift_JIS 対応

  • PDF ⇄ テキスト 変換

    PDF から文字を取り出す。文章を PDF にする。日本語・長い文書にも対応。

    全ページA4 縦・横

  • 文字列ツール

    Base64・URL エンコード、MD5・SHA-256 などのハッシュ、UUID の生成。

    URL セーフファイル → Base64

  • テキスト変換

    全角・半角、半角カナ、ひらがな・カタカナ、重複行の削除など。文字数も数えます。

    15種類の変換原稿用紙換算

データを外に出さないしくみ

  • 変換の処理は、すべてお使いのブラウザの中で動きます。
  • 貼り付けた文字や選んだファイルは、このサイトのサーバーに送られません。社内のデータや個人情報も安心して扱えます。
