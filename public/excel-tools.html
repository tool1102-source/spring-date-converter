Excel ⇄ CSV 変換

Excel ファイルを CSV に、CSV を Excel ファイルに変換します。中身を確認してからダウンロードできます。

ファイルはサーバーに送られません

Excel → CSV

CSV → Excel

Excel → CSV で気をつけていること

  • 空のセルがあっても列がずれません。
  • 数式のセルは、計算した結果の値を書き出します。
  • 日付や数値は、Excel の画面に表示されているとおりの形で書き出します。

CSV → Excel で気をつけていること

  • 文字コード（UTF-8 / Shift_JIS）と区切り文字を自動で判別します。
  • 郵便番号や社員番号のように先頭が 0 の値は、0 が消えないよう文字のまま入れます。
  • 列の幅は中身に合わせて自動で広げます。
