PDF ⇄ テキスト 変換

PDF から文字を取り出したり、文章を PDF にしたりできます。

ファイルはサーバーに送られません

PDF → テキスト

テキスト → PDF

印刷の画面が開きます。送り先（プリンター）で「PDF に保存」を選んでください。iPhone では共有ボタンから PDF として保存できます。

PDF → テキスト について

  • 何ページあっても、すべてのページから文字を取り出します。
  • 紙をスキャンしただけの PDF（中身が画像）は、文字の情報がないため取り出せません。
  • パスワードで保護された PDF は読み取れません。

テキスト → PDF について

  • ブラウザの「PDF に保存」機能を使うので、日本語も長い文章もきれいに PDF になります。
  • 文字の大きさ・用紙の向き・余白を選べます。
  • 長い行は、用紙の幅に合わせて自動で折り返します。
