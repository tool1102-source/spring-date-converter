JSON ⇄ CSV 変換

JSON と CSV・TSV を相互に変換します。貼り付けるかファイルを選ぶと、すぐに結果が出ます。

JSON → CSV のしくみ

  • オブジェクトの配列を、1件1行の表にします。項目名は全件から集めるので、件によって項目がちがっても大丈夫です。
  • 入れ子のオブジェクトは「user.name」のような列に展開します。配列は JSON の文字のまま入れます。
  • カンマ・改行・引用符を含む値は、自動で引用符で囲みます。

CSV → JSON のしくみ

  • 引用符で囲まれた値の中のカンマや改行も、正しく1つの値として読みます。
  • 「0012」のように先頭が 0 の値や、16桁以上の数字は、桁が消えないよう文字のまま残します。
  • 日本語版 Excel で保存した Shift_JIS の CSV ファイルも、文字化けせずに読めます。
