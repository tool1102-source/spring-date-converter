日付・Epoch Time 変換

UNIX時間（Epoch）と日時の相互変換と、日付の書き方の一括変換ができます。入力するとすぐに結果が出ます。

Epoch → 日時

日時 → Epoch

「2024-05-20T10:30:00+09:00」のように時差が書いてあれば、そちらを優先します。「2024年5月20日 10時30分」のような書き方も読めます。

日付の書き方をまとめて変換

1行に1つずつ日付を貼り付けると、すべての行を指定した書き方に変換します。

書き方の記号の一覧
記号意味例
yyyy / yy年（4桁 / 2桁）2024 / 24
MM / M月（2桁 / そのまま）05 / 5
dd / d日（2桁 / そのまま）09 / 9
HH / H時（24時間）07 / 7
mm / m分05 / 5
ss / s秒03 / 3
SSSミリ秒120
E曜日（出力のみ）月
'T'' で囲むとそのままの文字T

Epoch（UNIX時間）とは

  • 1970年1月1日 0時0分0秒（UTC）からの経過時間です。
  • 10桁なら秒、13桁ならミリ秒のことがほとんどです。このツールは桁数から自動で判別します。
  • 日本時間は UTC より9時間進んでいます（夏時間はありません）。

こんなときに

  • ログやデータベースに入っている数字の時刻を読みたいとき
  • API に渡す Epoch 値を作りたいとき
  • 表計算ソフトから出した日付の書き方をそろえたいとき
